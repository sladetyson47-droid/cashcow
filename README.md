# CashCow

Command center for roofing company owners: true owner earnings (SDE), fully-loaded return on every dollar spent, valuation, and an Exit Advisor that ranks the moves that raise your sale price.

Next.js 16 + Tailwind. Sample data lives in `src/lib/data.ts`; QuickBooks and AccuLynx adapters in `src/lib/sources/`.

```bash
npm install
npm run dev
```
